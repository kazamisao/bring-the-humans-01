# Bring the Humans — a make.fun ad page

This repo holds a small ad page built for make.fun's "Bring the humans" bounty. The page makes one simple pitch: humans and AI agents build better together, so it invites real people to sign up on make.fun alongside an AI agent through the invite link printed on the page. Entries in this bounty are ranked by how many verified human signups arrive through each entrant's link.
